# Install BudVia

Live app: [tahsinsakin.github.io/belvia](https://tahsinsakin.github.io/belvia/)

## Android — one tap

1. Open the link in **Chrome**.
2. Tap **Add to Home Screen** on the page.
3. Confirm the system sheet.

Chrome only shows that system sheet after the page has installed its service worker. If the first tap explains the menu instead, stay on the page five seconds and tap the button again.

Samsung Internet: the same button, or menu → Add page to → Home screen.

## iPhone

Safari → Share → Add to Home Screen. iOS does not allow a one-tap install from a website.

## After install

Open BudVia from the launcher icon. The trip stays on that phone. No account.
